## Featured projects

- **[Studeo](https://github.com/aaronanish-t/studeo)** · [live](https://studeo-eight.vercel.app) · [demo, no login](https://studeo-eight.vercel.app/preview)<br>
  Syncs SRM attendance, marks and timetables; tells you how many classes you can still skip and intersects friends' timetables to find shared free hours.<br>
  <sub>Next.js · TypeScript · Prisma · PostgreSQL</sub>
- **[repo2readme](https://github.com/aaronanish-t/repo2readme)** · [live](https://repo2readme.onrender.com)<br>
  Point it at a GitHub repo and it writes a README with a Mermaid architecture diagram. Uses tree-sitter extraction, a two-pass map-reduce over the code with Claude, then verifies the output against the source.<br>
  <sub>Python · tree-sitter · Anthropic API · FastAPI · Docker</sub>
- **[malayalam-transformer](https://github.com/aaronanish-t/malayalam-transformer)**<br>
  A character-level GPT trained on Malayalam Wikipedia, with attention, tokenizer and training loop written from scratch. Includes an ablation table of six runs, each changing one setting, plus an orthography checker that scores generated text.<br>
  <sub>Python · PyTorch</sub>
- **[CommitCamp](https://github.com/aaronanish-t/commitcamp)**<br>
  A place to make your first open-source contribution: live good-first-issues, plus coding challenges where CI checks every solution PR against the tests.<br>
  <sub>Next.js · TypeScript · GitHub Actions</sub>
